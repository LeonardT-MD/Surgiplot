# Installation and Deployment

## 1. Installation profiles

Surgiplot separates its numerical core from desktop rendering dependencies.

| Profile | Install target | Provides |
|---|---|---|
| Core | `.` | Python API, CLI, CSV/TSV/XLSX/JSON I/O, metrics, study tables |
| GUI | `.[gui]` | Core plus PySide6, Matplotlib, image texture support, hardware reporting |
| Rendered scene | `.[scene3d]` | GUI plus PyVista, PyVistaQt, and VTK |
| Development | `.[dev]` | Test, lint, and build tools |

The core does not require Qt, VTK, PyVista, Matplotlib, or a model runtime. Model weights and segmentation frameworks are not dependencies of this repository.

## 2. Prerequisites

- CPython 3.10 or newer;
- `pip` capable of installing PEP 517 projects;
- Git when cloning rather than downloading an archive;
- a graphical desktop session for the GUI;
- adequate RAM and a functional OpenGL stack for large rendered scenes.

Python 3.11 or 3.12 is recommended for the broadest binary-wheel availability across scientific and GUI packages.

## 3. Clone or download

### Git

```bash
git clone https://github.com/LeonardT-MD/Surgiplot.git
cd Surgiplot
```

### GitHub archive

1. Open the repository’s **Code** menu.
2. Select **Download ZIP**.
3. Extract the archive.
4. Open a terminal in the extracted repository root, where `pyproject.toml` is located.

Do not run Surgiplot from inside the compressed archive.

## 4. Isolated installation with `venv`

### macOS and Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install '.[scene3d]'
```

### Windows PowerShell

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install ".[scene3d]"
```

If PowerShell blocks activation, either apply an appropriate user-scoped execution policy or invoke `.venv\Scripts\python.exe` directly. Do not disable system security controls globally solely for this installation.

## 5. Conda installation

### Installer script

On macOS or Linux:

```bash
bash surgiplot/scripts/install_conda.sh surgiplot
conda activate surgiplot
```

The script:

1. verifies that `conda` is available;
2. reuses an existing environment with the requested name or creates Python 3.11 environment;
3. resolves the repository root from the script location;
4. installs the package in editable mode with `scene3d` dependencies.

### Environment file

From the repository root:

```bash
conda env create -f surgiplot/env/surgiplot_master.yml
conda activate surgiplot
```

The environment file intentionally does not install PyTorch, Transformers, segmentation models, or model weights.

## 6. Installation modes

### Standard install

```bash
python -m pip install .
```

This copies the built package into the environment. Later edits to the repository do not affect the installed package until it is reinstalled.

### Editable development install

```bash
python -m pip install -e '.[gui,dev]'
```

Editable mode points the environment at the source checkout. Use it for development, not for a controlled analysis workstation unless the exact Git revision and working-tree status are recorded.

## 7. Verification

Run:

```bash
surgiplot version
surgiplot --help
python -c "import surgiplot; print(surgiplot.__version__)"
```

For GUI profiles:

```bash
surgiplot-gui
```

For a headless import check:

```bash
python -c "from surgiplot.gui.app import MainWindow; print(MainWindow.__name__)"
```

For development validation:

```bash
python -m pytest
ruff check surgiplot tests
python -m build
```

## 8. Optional 3D backend selection

`SURGIPLOT_3D_BACKEND` controls the rendered-scene backend:

- `auto` — PyVista except where the application selects the safer Matplotlib path;
- `pyvista` — request PyVista/VTK;
- `matplotlib`, `mpl`, or `safe` — disable PyVista and use the Matplotlib path.

Example:

```bash
SURGIPLOT_3D_BACKEND=safe surgiplot-gui
```

On Windows PowerShell:

```powershell
$env:SURGIPLOT_3D_BACKEND = "safe"
surgiplot-gui
```

The environment variable changes rendering only. Metric results remain generated by the shared metric core.

## 9. Upgrading

For a Git checkout:

```bash
git status --short
git pull --ff-only
python -m pip install --upgrade .
```

Do not pull over uncommitted analytical code without reviewing the diff. For reproducible research, record the pre-upgrade and post-upgrade commit hashes:

```bash
git rev-parse HEAD
```

## 10. Uninstalling

For `venv`, deactivate and remove only the specific environment directory after verifying its path. For a shared environment:

```bash
python -m pip uninstall surgiplot
```

For Conda:

```bash
conda deactivate
conda env remove -n surgiplot
```

Removing the Python environment does not remove input datasets or exported results.

## 11. Troubleshooting

### `ModuleNotFoundError: PySide6`

The core profile was installed. Install `.[gui]` or `.[scene3d]`.

### PyVista or VTK crashes during startup

Start with the safe backend:

```bash
SURGIPLOT_3D_BACKEND=safe surgiplot-gui
```

Then verify graphics drivers, Python architecture, and package compatibility before forcing PyVista.

### `surgiplot` command not found

Confirm that the intended environment is active and inspect:

```bash
python -m pip show surgiplot
python -c "import sys; print(sys.executable)"
```

The command-line module can also be invoked directly:

```bash
python -m surgiplot.cli.app --help
```

### Package version appears stale

An older installation may be taking precedence over the current checkout. Inspect:

```bash
python -c "import surgiplot; print(surgiplot.__file__); print(surgiplot.__version__)"
```

Reinstall into the active environment. Avoid mixing system Python, Conda, Homebrew Python, and a project `venv` in the same shell session.

## 12. Reproducible deployment record

For every controlled workstation or study environment, retain:

- operating system and architecture;
- Python version;
- Surgiplot Git commit and package version;
- `python -m pip freeze` or Conda environment export;
- selected 3D backend;
- input coordinate system and units;
- metric standardization parameters;
- test result for the installed revision.
